# Objects and components

UnityEngine.Object, GameObject, Component and Transform expose the M20 source surface over the same native identities, lifecycle and scene as the retained Axiom.Gameplay API. Their public vectors and rotations use floats. Other API areas continue to use their documented namespaces until their milestones are accepted. A declaration match is separate from per-overload behavior certification.

Runtime transforms retain full affine matrices, including shear and zero-scale local coordinates. Authored reparenting still rejects shear that cannot be saved as plain TRS. Runtime changes are discarded on Stop. Runtime cloning snapshots serialized fields and references; asynchronous clones defer scene activation, support cancellation and use the owned integration queue. Explicit limits remain 65,536 entities, 32 attached physical scripts and 128 wire operations per phase.

CreatePrimitive creates owned Sphere, Capsule, Cylinder, Cube, Plane and Quad mesh assets and the corresponding MeshFilter, MeshRenderer and collider. Capsule and Cylinder use a capsule collider; Plane and Quad use finite one-sided mesh surfaces in the Rust CPU solver. Normal runtime scenes expose Unity 6.3’s documented default scene culling mask; editor preview-scene mask controls belong to the later editor milestone.

Mesh, render and collider facades supplied as M20 dependencies expose their implemented members only; their full API areas remain separate milestones. Unsupported asset cloning or component construction fails explicitly. See the generated namespace comments and the exact source before using an API.

## Experimental distribution

Prepared publications now support a commit-pinned Experimental channel, independently of approval for main. Exact-commit CI must pass. The release manifest and package retain the PR, branch, commit and CI run; Platform0.1.8 can download/install it side by side and activate it explicitly. The publication workflow uses read-only candidate builds and a separate pinned trusted publisher. Until the workflow exists on main, a matching experimental tag bootstraps a passed candidate. A successful main CI publishes a new stable numeric release; no existing publication or recovery ref is overwritten. Runtime SDK8/native formats1 and M19 audit scope are unchanged.
